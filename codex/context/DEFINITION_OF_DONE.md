# Definition of Done

Uma tarefa só está pronta quando os itens aplicáveis forem comprovados.

## Funcional
- [ ] requisito identificado;
- [ ] happy path;
- [ ] entradas inválidas;
- [ ] loading/empty/error;
- [ ] persistência;
- [ ] reflexo correto entre front, API e banco.

## Autorização
- [ ] rota protegida no servidor;
- [ ] papel/ownership verificado;
- [ ] teste negativo executado.

## Dados
- [ ] schema/migration/script reproduzível;
- [ ] constraints coerentes;
- [ ] dados privados não vazam;
- [ ] exclusão/cascata avaliada;
- [ ] seed usa dados fictícios.

## LGPD
- [ ] consentimento/termo quando aplicável;
- [ ] somente dados necessários publicados;
- [ ] feedback privado;
- [ ] CPF/CNPJ protegido;
- [ ] logs sem dados sensíveis.

## Front-end
- [ ] sem erro de console relevante;
- [ ] responsivo;
- [ ] estados de erro;
- [ ] integração real;
- [ ] tipagem.

## Acessibilidade
- [ ] teclado;
- [ ] foco;
- [ ] semântica;
- [ ] labels;
- [ ] erros associados;
- [ ] contraste;
- [ ] modal;
- [ ] zoom/reflow;
- [ ] teste automatizado;
- [ ] teste manual.

## Testes
- [ ] unitário quando adequado;
- [ ] integração;
- [ ] E2E crítico;
- [ ] CT correspondente registrado;
- [ ] evidência.

## Entrega
- [ ] lint;
- [ ] typecheck;
- [ ] build;
- [ ] docs existentes atualizadas;
- [ ] nenhum secret;
- [ ] diff revisável.
