# Agente 1 — Front-end e integração

Só trabalhe em lacunas confirmadas pela auditoria.

Prioridades:
- cadastro em 4 passos;
- mural;
- detalhes;
- busca/filtros;
- feedback;
- login/painel;
- Área do Artista somente se confirmada no escopo;
- integração API real;
- responsividade.

Antes de alterar, faça uma tabela:
`Tela | chamada API | estado atual | problema | RF/CT`.

Não redesenhe a aplicação.
Preserve o design system atual.
Corrija estados loading/empty/error.
Não use mock quando a funcionalidade deve estar conectada à API.

Execute build, lint/typecheck e testes relevantes.
Atualize a matriz de rastreabilidade.
